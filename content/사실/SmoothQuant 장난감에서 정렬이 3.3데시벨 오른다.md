같은 장난감에 SmoothQuant(α = 1/2)를 입히자 활성값 농도는 1.0에서 9.5 dB로 8.5 dB 오르고 가중치 농도는 13.3에서 8.0 dB로 5.3 dB 떨어졌으며, 정렬은 −30.03에서 −26.69 dB로 3.3 dB 올랐다. W4A4 합은 근사 13.3 dB, 실측 13.1 dB로 하다마드의 15.4 dB보다 낮지만, 이득의 출처가 농도 거래와 정렬 개선 두 갈래다.
