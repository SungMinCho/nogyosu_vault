스프라이트의 파일 시스템 코드가 block이라는 변수 이름을 어떤 곳에서는 물리 블록 번호로, 어떤 곳에서는 논리 블록 번호로 쓰다가, 논리 번호를 담은 block이 물리 번호가 필요한 자리에 쓰여 상관없는 디스크 블록 하나를 0으로 덮어쓴 버그다. 저자를 포함해 여러 사람이 그 코드를 읽었지만 이름이 그린 그림에 가려 아무도 보지 못했고, 저자가 여섯 달 계측 끝에 찾았다. 해법은 fileBlock과 diskBlock으로 이름을 가르는 것이고, 2판은 서로 다른 타입을 쓰면 더 좋다고 덧붙였다.
