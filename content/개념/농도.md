CAT 논문이 정의한 양으로, 양자화되는 벡터의 에너지(제곱한 2-노름)를 양자화 범위의 제곱으로 나눈 비다. 값이 얼마나 뾰족하게 튀는지, 곧 이상치의 정도를 재며, 이상치가 심할수록 낮고 에너지가 모든 좌표에 고르게 퍼질수록 높다. 신호 대 양자화 잡음비를 이루는 네 인수(상수 12, 비트, 농도, 정렬) 가운데 하나이고, 회전으로 바꿀 수 있다.

- **[[CAT 01강 눈금을 정하는 자와 눈금을 읽는 자|1강]]** — 논문은 값이 얼마나 뾰족하게 튀느냐, 즉 이상치의 문제를 농도(concentration)라 부른다.
- **[[CAT 02강 두 잡음은 어떻게 합쳐지는가|2강]]** — 두 조각을 하나씩 더 잘게 가르는 다음 강에서 농도가 처음 이름을 얻는다.
- **[[CAT 03강 한 조각을 세 인수로 가르다|3강]]** — 잡음의 크기는 가장 큰 값이 정하고 신호의 크기는 모든 값이 정하는 비대칭이 농도라는 양의 정체다.
- **[[CAT 04강 비트와 농도, 그리고 거꾸로 쓰인 낱말|4강]]** — 원문 2.1절은 비트, 농도, 정렬 순서로 네 인수가 얽히는 방식을 들어 올린다.
- **[[CAT 05강 정렬, 또는 어긋난 눈금|5강]]** — 정렬이 1/d 수준인데도 SQNR이 무너지지 않는 것은 농도가 차원에 비례해 크기 때문이다.
- **[[CAT 06강 기존 변환들을 해부대에 올리다|6강]]** — 원문 3절은 T가 농도와 정렬을 각각 어떻게 움직이는지로 기존 변환들을 해석한다.

## 다른 책에서는

- **[[신경망 양자화 강좌]]** — CAT 논문이 정의한 양으로, C = n/(4κ²)로 쓰면 2강의 첨두비 κ를 다시 쓴 것이다.
- **[[회전 양자화의 계보]]** — C(x) = E‖x‖² / E\[r(x)²\]로, r(x)는 양자화 범위(대칭이면 2·max|xᵢ|)다. 풀면 C = n·rms²/(4·max²) = n/(4κ²), 곧 첨두비의 역제곱에 차원 수를 곱한 것이다. 논문은 KurTail의 첨도와 친척이라고 적었다. 원소 하나만 살아 있으면 C = 1/4, 곧 −6 dB로 가장 나쁘다. 회전(직교 변환)이 고치는 것은 이 인수뿐이다.
