실수 x 이상인 정수 가운데 가장 작은 것 ⌈x⌉이다. 관계로 쓰면 ⌈x⌉ ≤ n ⇔ x ≤ i(n)이므로 포함 i: ℤ→ℝ의 왼쪽 수반이다. 내림과 함께 ⌈·⌉⊣i⊣⌊·⌋라는 수반의 사슬을 이루며, 정수로 실수를 근사하는 방법은 위에서 하나, 아래에서 하나, 정확히 이 둘이다. ⌈-1.5⌉ = -1이다.

## 강의에서

- **[[범주론 08강 수반 I|8강]]** — 올림은 ⌈x⌉ ≤ n ⇔ x ≤ i(n)을 만족하므로 포함의 왼쪽 수반이며, 포함 하나에 왼쪽으로 올림, 오른쪽으로 내림이 붙어 수반의 사슬을 이룬다.
