CS190 HTTP 서버 과제에서 학생들이 흔히 소켓에서 요청을 읽는 클래스와 읽은 문자열을 파싱하는 클래스를 따로 만든 실수다. 요청을 다 읽으려면 머리글의 Content-Length를 파싱해야 하므로 두 클래스 모두 요청 구조를 알게 되고 파싱 코드가 중복된다. 시간적 분해가 누수를 낳은 전형이며 처방은 두 클래스를 합치는 것이다.
