정상적인 경우가 가장자리 조건까지 추가 코드 없이 자동으로 처리하도록 설계해 if 문투성이의 특수한 경우를 없애는 기법이다. 편집기에서 선택 영역이 언제나 있다고 정하고 아무것도 선택되지 않은 상태를 시작과 끝이 같은 빈 선택 영역으로 보면, 지우기와 복사가 아무 if 없이 올바르게 동작한다. 10장의 오류를 정의로 없애기와 뿌리가 같다.
