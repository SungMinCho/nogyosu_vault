되르너의 과밀 시뮬레이션 백서에 실린 실제 예제로, 확실성 필요 NI\[cert\] = 0.6, 유능감 필요 NI\[comp\] = 0.7(잘 모르겠고 자신도 없다), 기본 확인값 0.2, 기본 각성 0.5, 각성 가중치 0.5, 억제 가중치 0.85를 넣으면 확인 = 0.6 × 0.7 + 0.2 = 0.62, 도피 = 0.42, 공격 = 0.6 × 0.3 = 0.18, 각성 = 0.5 + 0.7² × 0.5 = 0.745, 억제 ≈ 0.63, 해상도 ≈ 0.37이 된다. 깨어 있고 자주 둘러보고 싸우기보다 도망치려 하고 거칠게 보는 불안·공포의 윤곽이다. 같은 식에 NI\[comp\] = 0.2를 넣으면 공격 0.48이 도피 0.12를 이기지만 각성은 0.52로 오히려 내려가, 이 식만으로는 분노에 닿지 못하고 해볼 만한 장애물 앞의 공격 경향까지만 간다.
