C의 정수 나눗셈은 0 쪽으로 자르므로 -7 / 2 = -3, -7 % 2 = -1이 된다. 내림 나눗셈이라면 -7 = 2×(-4)+1로 몫 -4, 나머지 1이 나와 나누는 수가 양수인 한 나머지가 늘 0 이상인 규칙이 선다. 파이썬의 //가 내림을 택한 이유이다.
