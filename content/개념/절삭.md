실수를 0 쪽으로 잘라 정수로 만드는 연산으로, C 언어의 (int) 형변환이 이것이다. (int)(-1.5)는 -1이다. x = -1.5, n = -1에서 내림의 동치가, x = 2.7, n = 2에서 올림의 동치가 깨지므로 어느 쪽 수반도 아니다. 부호에 따라 두 규칙을 이어 붙인 것이라 한 줄짜리 보편 성질을 갖지 못하고, -7/2 = -3, -7 % 2 = -1 같은 버그의 원천이 된다. 파이썬의 //는 이 때문에 내림을 택했다.
