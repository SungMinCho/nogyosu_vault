여러 예외를 코드 한 곳에서 처리하는 기법이다. 웹 서버의 URL 처리기들이 매개변수 예외를 각자 잡지 않고 맨 위 디스패처의 처리기 하나가 상태 코드와 메시지로 오류 응답을 만들게 하면, 디스패처는 개별 오류를 모르고 매개변수 메서드는 HTTP 응답을 모르는 캡슐화가 이루어진다. '그만두고, 정리하고, 다음 요청으로'라는 서버의 모양이며, 예외가 여러 층을 거슬러 올라갈 때 가장 잘 먹힌다.
