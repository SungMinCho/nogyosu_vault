실수 x 이하인 정수 가운데 가장 큰 것 ⌊x⌋이다. '가장 큰'을 관계로 쓰면, 정수 n을 실수로 본 i(n)에 대해 i(n) ≤ x ⇔ n ≤ ⌊x⌋가 모든 n에서 성립한다는 것이 완전한 정의이다. 정수 세계 안에서 x를 아래로부터 가장 잘 대리하는 정수이며, 포함 i: ℤ→ℝ의 오른쪽 수반이다. ⌊-1.5⌋ = -2이다.

## 강의에서

- **[[범주론 08강 수반 I|8강]]** — ⌊x⌋는 i(n) ≤ x ⇔ n ≤ ⌊x⌋라는 한 줄로 완전히 정의되며, 이는 포함 i가 내림의 왼쪽 수반이라는 말이다.
