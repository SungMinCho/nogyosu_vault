선분 전체를 비율 r로 크게 자르고(C + D = r(A + B)) 각 부분을 같은 비율로 다시 자르면(B = rA, D = rC), 첫 식에서 C(1 + r) = rA(1 + r), 곧 C = rA = B가 되어 비율이 무엇이든 가운데 두 칸 B와 C는 같다. 선 전체를 L이라 하면 A = L/(1+r)², B = C = rL/(1+r)², D = r²L/(1+r)²이고, r = 2, L = 9면 1, 2, 2, 4다. 강의는 네가레스타니가 '더 정확한' 식으로 적은 D : B = C : A가 B = C를 함축한다는 것을 저자도 플라톤도 명시하지 않으며, r을 황금비로 두면 감각 세계 A + B가 맨 위 칸 D와 같은 길이(L = 1이면 약 0.382)가 된다고 덧붙인다.
